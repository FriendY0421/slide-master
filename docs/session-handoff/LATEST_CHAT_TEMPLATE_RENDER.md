# Latest Chat Template Render Checkpoint

Updated: 2026-08-25 10:56 KST

For new PPT requests on ChatGPT, the template-selection step is valid only when the exact registered template visuals are rendered inside the current conversation before the user is asked to choose.

Text names/numbers alone are a failed selection surface. External HTML is fallback only after inline rendering is unavailable even after one retry.
