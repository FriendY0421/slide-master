# Missing-file recovery on Aro and other computers

User direction recorded 2026-11-08 (Asia/Seoul). Keep the current PC as the
preferred working environment while it is available. This policy concerns
recovering missing job/source files after reset or environment changes; it does
not provision a computer, install the plugin or relocate its MCP server.

## Communication and execution

| Destination | Required behavior |
| --- | --- |
| User's already identified Aro virtual computer | If required files are missing, use the existing authorized Drive connection to retrieve the verified private capsule, validate it, and resume the actual approved revision without a separate setup tutorial or repeat permission question. Include recovery in the eventual result record. |
| Another computer | Before downloading/working, explain briefly the destination, files/size, checks and next work. Then proceed within existing authorization; the informational notice is not a new approval gate. |
| Unidentified environment | Give the other-computer notice. Do not infer Aro identity from a display name, an unrelated task or a shared filesystem. Ask only if identity is needed for access or another consequential decision. |

Existing analysis/design/template/preset/current-storyline approval requirements
remain in force. Automatic recovery is not automatic approval of new production.
If no genuine approved revision is available, recover files, inspect them, and
present the required analysis/plan before authoring.

## Recovery sequence

1. Read the latest repository handoff and this policy. Find the existing private
   Drive recovery entry from the user's supplied link or authenticated metadata;
   if absent, search for the exact authorized capsule name below. Resolve any
   duplicate using version and hash, not filename alone. Never request public
   sharing or put Drive IDs/links in the public repository.
2. Check actual destination storage and existing runtimes. Download only the
   needed capsule into a new dedicated directory; preserve existing originals
   and incomplete work. If required files already exist with matching hashes,
   reuse them instead of downloading again.
3. For the current baseline, verify `SlideMaster_Portable_045_0d66249.zip`:
   **19,444,972 bytes**, SHA256
   `ac3a8266191604223cdb1a51a929f686e83de185849cabd7010b536dbbc2e383`.
   This is the pinned baseline, not a claim that it contains later changes.
   Prefer a later verified job manifest only when actual evidence establishes it.
4. Extract without overwriting existing work. Read `CONTINUE_WITH_ARO.md`, job
   manifest and file hashes; use the current repository policy if the archive's
   older communication instructions differ. Reject mismatched or unsafe archive
   paths, missing/corrupt files and unverified replacement inputs.
5. Reuse supplied Python/Node/render tools. Resolve relative asset/font paths,
   run the route owner's existing validation, then reopen/render the exact output
   before private delivery. Report unsupported checks separately. A successful
   download/extraction is not proof that production dependencies are available.
6. Preserve the genuine approval/source state, final PPTX and QA receipts privately
   in Drive, and public-safe progress in PR #14. Verify durable bytes/access before
   treating local copies as disposable. Do not delete other projects or caches.

The capsule contains public source, temporary OFL Pretendard and synthetic QA
fixtures, not the user's company original or a new business brief. Never use
synthetic fixtures as a substitute for a missing user attachment. Do not fetch,
install or embed Samsung fonts without their separately established use rights.

## Exceptions and limits

Missing Drive authentication/access, an ambiguous capsule, insufficient space,
missing software or a disconnected Picker is a real exception. Report its exact
cause, checks already performed, available no-cost alternative and minimum user
action together. Continue independent permitted inspection. Do not install,
grant access, transfer secrets, spend money or start a replacement service under
the automatic-download instruction.

Original Picker requires its existing reachable server/tunnel. A source ZIP
cannot make it PC-independent. Use the documented real-preview fallback only
with its actual reason and genuine template/preset confirmation. Native Windows
PowerPoint availability and Samsung rendering remain separate acceptance items.
