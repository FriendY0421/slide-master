ZIP SHA256: `81365888a7a01aeea90d56c6ddddcb007f6282ced5814d48e9571cd0cb7be61e`.
ZIP을 풀고 README부터 읽은 뒤 복사본을 열어 편집한다. 기존 전후 이미지는
PARTIAL, PowerPoint 화면은 요구 글꼴 미확인, Pretendard 화면은 임시 검증으로

## 미완료 원인과 최소 다음 행동

1. **클라우드 전체 왕복:** 실제 사용자 첨부와 현재 구성 확인이 없다.
   기존 Cloud Work 시험 대화에 비민감 [합성 PNG](evidence/synthetic-cloud-input-20261013.png)를
   첨부하고 그곳에 제시되는 현재 구성안을 확인한다. 공개 URL·가짜 파일 ID로
   소유권을 대신하지 않는다. 그 뒤 제작→검수→비공개 전달→정확한 수령자 열기
   기록이 필요하다. 한 번 실패한 Picker 429는 반복 호출하지 않았다.
2. **회사 양식/보존 영역:** 원본 PPTX와 변경/보존 영역 설명이 없다.
   회사 원본을 비공개로 제공하면 원본 패키지/화면과 대조할 수 있다.
   기존 생성 결과물은 회사 원본으로 간주하지 않는다.
3. **Samsung:** 파일 보유만 확인됐고 사용 조건은 없다.
   로컬 제작/렌더 및 세션 임시 등록 승인, 클라우드 설치, 서버 렌더,
   산출물 임베딩을 각각 확인한다. 현재 등록·업로드·임베딩은 하지 않는다.
4. **운영 연결:** 메인 편집 대상은 확인했지만 저장 transport·사용자/파일 접근
   범위·기존 소스 대응이 미확인이다. 확인된 기존 대상의 공식 설정이 필요하며
   새 플러그인으로 대신하지 않는다. 운영 반영이 가능해지면 대상/변경/영향/
   권한·비용/보존·복구를 묶어 승인받는다.

PC 기반 Picker와 Windows PowerPoint 검수는 PC가 필요하다. Cloud Work는
실제 Linux 시험까지만 확인됐고, 이 부품들이 자동 이전되지 않는다.
보존 기간·다운로드 범위·사용량/비용 한계는 시험 도구에서 확정하지 못했다.

## 중지·복구

야간 로컬 예약은 07:00 KST 종료 시각을 가진다. 필요 시 Codex 자동화에서
중지한다. 기존 Cloud Work 시험을 닫아도 새 서버를 종료할 필요는 없다.
원본·복구본은 기존 비공개 review/backup-*에 보존했다. ZIP 삭제는 원본을
삭제하지 않는다. 후보 소스 복구는 변경 커밋의 검토된 revert로 수행하고,
다른 운영 checkout의 미완료 변경이나 관리 캐시를 덮어쓰지 않는다.
실제 운영 설치가 없으므로 기존 main/설치 0.4.2는 그대로다.

미확인 입력 이후의 조건은 사용자 확인 전까지 진행하지 않는다. 변경 없이
기다린 실행을 추가 작업·검증 성과로 계산하지 않는다. 기상 작업은 제외했다.
