## Executed checks

The audit called existing CLIs in a gitignored `projects/_smoke_cloud_entry`
workspace and reused their validators. Main catalog discovery returned 21 ACTIVE
entries and six relevant real candidate/detail source sets at the recorded SHA.
Those counts describe this snapshot, not a permanent hardcoded catalog.

Complete builtin/custom briefs ask no repeated intake question. Removing the
preset asks only for the preset; removing custom sample/size policies bundles
only those missing inputs. Builtin selection reads the catalog and preset from
the same refreshed immutable main commit; an expected preview SHA mismatch,
network refresh failure, deprecated/unknown template, unknown preset, missing
confirmation and missing recommended-picker evidence are rejected.

A valid synthetic selection plus storyline initializes a project. Missing and
mutated storyline approval fail. Custom source analysis, plan check, runtime/font
preparation and native exemption validation pass; an unconfirmed native plan
fails before producing a file. The confirmed native plan binds its exact source
SHA. This audit leaves generation to the existing selected route owner.

font/size/count/rules; custom accepts a native template or example, or a visual

by final QA. Native plans carry `requested_slide_count`; mismatched apply is
blocked. Actual output read-back remains the selected route owner's duty.
